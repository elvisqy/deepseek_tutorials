# DeepSeek Tutorials

DeepSeek 模型运行机制与推理优化的可视化教程集合。

## 教程

- [SWA Replay 流程](./swa-bound-replay/)：以动态流程说明 DeepSeek V4.1-Flash 在 Replay 开启和关闭时的窗口计算、缓存命中、逐层 SWA 恢复以及双缓存命中边界。

## 阅读方式

每个教程都提供自包含的 `index.html`。字体、样式和交互逻辑已经内嵌，下载后可以直接使用浏览器打开，不依赖额外资源文件。
